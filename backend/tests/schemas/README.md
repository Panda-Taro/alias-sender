# Vendored AMWA IS-04 v1.3 resource schemas

These files are unmodified copies of the official JSON schemas from
[AMWA-TV/nmos-discovery-registration](https://github.com/AMWA-TV/nmos-discovery-registration)
(`v1.3.x` branch, `APIs/schemas/`), vendored here so `test_nmos_schema_compliance.py`
can validate the resource JSON this system generates against the real
IS-04 schemas without a network dependency at test time.
